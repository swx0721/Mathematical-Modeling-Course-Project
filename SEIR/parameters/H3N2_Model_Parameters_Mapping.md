## 四、优化参数 (Optimization Parameters)

### 4.1 β₀ (beta0) - 基础传播率

**模型配置值**: 初始0.35, 边界[0.01, 3.0]

| 属性               | 内容                         |
| ------------------ | ---------------------------- |
| **参数符号** | β₀                         |
| **物理意义** | 基础传播率，决定疾病传播速度 |
| **模型初值** | 0.35                         |
| **拟合边界** | [0.01, 3.0]                  |
| **单位**     | day⁻¹                      |
| **数据来源** | 拟合参数                     |
| **覆盖状态** | ⚠️ 需文献约束              |

**文献先验对比**:

| 来源               | R₀估计        | 对应β₀       | 说明               |
| ------------------ | -------------- | -------------- | ------------------ |
| 中国CDC            | 1.3-1.8        | 0.33-0.45      | 季节性H3N2         |
| WHO (2017)         | 1.5-2.0        | 0.38-0.50      | 季节性流感         |
| Park et al.        | 1.3 (SE 0.05)  | 0.33           | 美国/法国/澳大利亚 |
| France (单季H3N2)  | 1.5            | 0.38           | 单季A/H3N2         |
| England & Wales    | 1.4-2.6        | 0.35-0.65      | 多季数据           |
| **模型初值** | **~1.4** | **0.35** | 合理范围内         |

**计算公式**: β₀ = R₀ × γ = R₀ / 感染期

对于R₀=1.4, γ=0.25: β₀ = 1.4 × 0.25 = 0.35

**关键发现**:

- 季节性流感R₀估计: 1.28 (IQR: 1.19-1.37) [^9]
- 2009 H1N1大流行: R₀ = 1.4-1.6 (初始估计) [^10]
- 1951年英格兰/加拿大流感: 更高的R₀估计 [^11]

**参考文献**:

- [^9] 季节性流感再生数估计, 多研究汇总
- [^10] Fraser C, et al. Science. 2009
- [^11] Vynnycky E, et al. 2007

### 4.4 k - 观测方程缩放系数*（已修改）*

**模型配置值**: 初始8.0, 边界[0.1, 40.0]

| 属性               | 内容                           |
| ------------------ | ------------------------------ |
| **参数符号** | k                              |
| **物理意义** | 模型感染率到ILI%观测的缩放系数 |
| **模型初值** | 8.0                            |
| **拟合边界** | [0.1, 40.0]                    |
| **单位**     | 无量纲                         |
| **数据来源** | 拟合参数                       |
| **覆盖状态** | ⚠️ 需文献约束                |

**文献先验**:

| 来源                 | 推荐值        | 说明              |
| -------------------- | ------------- | ----------------- |
| Shaman et al. (2013) | 2-15          | 从ILI+到真实感染  |
| 实时预测研究         | 2.5-5.0       | 高毒力季节用低值  |
| 香港研究             | 由滤波器估计  | γ = p(m)/p(m\|i) |
| **模型初值**   | **8.0** | 偏高，需验证      |

**计算公式**: ILI+ = ξ / γ, 其中γ = p(m)/p(m|i)

- p(m): 任何人因任何原因就医的概率
- p(m|i): 流感感染者就医的概率

**关键发现**:

- 缩放因子γ随流感毒力变化: 毒力越高，感染者就医概率越高，γ越小 [^13]
- 2012-2013高毒力季节: γ=2.5 [^13]
- 一般季节: γ=5-15 [^13]

**参考文献**:

- [^13] Shaman J, et al. PNAS. 2013; Real-Time Influenza Forecasts

## 九、ILI到真实感染换算参数 (Virology-to-ILI Mapping)

### 9.1 换算公式

```
真实感染数 = ILI病例数 × 病毒阳性率 / (P × Q × C × S × T)
```

### 9.2 各参数文献值

| 参数                 | 符号 | 值          | 来源                 | 说明       |
| -------------------- | ---- | ----------- | -------------------- | ---------- |
| 有症状感染比例       | P    | 58.3%-74.5% | Carrat et al. (2008) | Meta分析   |
| ILI占symptomatic比例 | Q    | 26.0%-42.0% | 北京研究; 广州研究   | 中国数据   |
| 就诊率               | C    | 50.5%-76.2% | NHSS (2008)          | 年龄别差异 |
| 采样成功率           | S    | 80%-90%     | 北京CDC              | -          |
| 检测灵敏度           | T    | 95%-100%    | PCR标准              | -          |

### 9.3 综合乘数因子

| 来源              | 乘数因子 | 说明             |
| ----------------- | -------- | ---------------- |
| 北京2009 H1N1研究 | ~167倍   | H1N1pdm09        |
| 综合估算          | 3-5倍    | 从ILI+到真实感染 |

## 十、关键建议与待办事项

### 10.1 高优先级修正

1. **免疫衰减率ω的约束**

   - 当前: 0.01 day⁻¹ (69天半衰期)
   - 建议: 0.00027-0.00055 day⁻¹ (3.5-7年半衰期)
   - 依据: Kucharski et al. (2018) [^6]
2. **季节性相位φ的初值**

   - 当前: 0.0
   - 建议: -π/4 to -π/2 (对应12月-1月峰值)
   - 依据: 中国流感季节性研究 [^12]
3. **传播率β₀的边界**

   - 当前: [0.01, 3.0]
   - 建议: [0.25, 0.65] (对应R₀ 1.0-2.6)
   - 依据: 季节性流感R₀估计 [^9]

### 10.2 中优先级验证

1. **观测缩放系数k的范围**

   - 建议验证: 2-15范围是否合理
   - 依据: Shaman et al. (2013) [^13]
2. **季节性振幅a的约束**

   - 建议: [0.1, 0.3]
   - 依据: 温带地区季节性模式
3. **月度基线校准**

   - 建议: 使用CNISN实际数据校准
   - 数据来源: 中国流感监测网络

### 10.3 低优先级补充

1. **H3N2特异性权重w_h3**

   - 需更多H3N2传播动力学研究支持
2. **峰值响应指数p**

   - 需通过敏感性分析确定合理范围
3. **历史季节性权重w_season**

   - 需混合模型研究支持
