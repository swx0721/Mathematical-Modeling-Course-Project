1. 生物学转移率 (Biological Transition Rates)
================================================================================

参数         │ 推荐值              │ 对应时间          │ 文献来源
─────────────┼─────────────────────┼───────────────────┼────────────────────────
σ (潜伏期倒数) │ 0.50 - 0.71 day⁻¹  │ 1.4 - 2.0 days    │ 中国CDC指南(2023)
             │                     │                   │ Vink et al. (2014)
─────────────┼─────────────────────┼───────────────────┼────────────────────────
γ (感染期倒数) │ 0.24 - 0.33 day⁻¹  │ 3.0 - 4.1 days    │ Carrat et al. (2008)
             │                     │                   │ WHO (2017)

关键发现:
• 甲型流感中位潜伏期: 1.4天 (95%CI: 1.3-1.5)
• H3N2代间距: 3.1-3.5天 (中国CDC指南)
• 成人平均排毒期: 4.1天 (范围: 3-8天)
• 症状出现前1-2天即可排毒

4. 病毒学到就诊行为映射 (Virology-to-ILI Mapping)
================================================================================

参数                    │ 推荐值/范围         │ 文献来源
────────────────────────┼─────────────────────┼────────────────────────────
P (有症状感染比例)        │ 58.3% - 74.5%      │ Carrat et al. (2008)
                        │                    │ Meta分析
────────────────────────┼─────────────────────┼────────────────────────────
Q (ILI占symptomatic比例)  │ 26.0% - 42.0%      │ 北京研究; 广州研究
────────────────────────┼─────────────────────┼────────────────────────────
C (就诊率)               │ 50.5% - 76.2%      │ 第四次国家卫生服务调查
                        │ (年龄别)            │ (2008)
────────────────────────┼─────────────────────┼────────────────────────────
S (采样成功率)           │ 80% - 90%          │ 北京CDC研究
────────────────────────┼─────────────────────┼────────────────────────────
T (检测灵敏度)           │ 95% - 100%         │ PCR检测标准
────────────────────────┼─────────────────────┼────────────────────────────
乘数因子 (总感染/ILI)     │ ~167倍 (H1N1pdm09) │ 北京2009年H1N1研究

【ILI到真实感染换算公式】
═══════════════════════════════════════════════════════════════════════════════

真实感染数 = ILI病例数 × 病毒阳性率 / (P × Q × C × S × T)

综合乘数因子 ≈ 3-5倍 (从ILI+到真实感染)

关键建模建议
================================================================================

1. 免疫参数ω的约束 (防止漂移):
   ─────────────────────────────────────────────────────────────────────────
   • 建议先验: ω ~ Uniform(0.0002, 0.0008) day⁻¹
   • 对应保护半衰期: 2.4-9.6年
   • H3N2应使用较短的半衰期 (3-5年)

2. ILI指标稳定性问题:
   ─────────────────────────────────────────────────────────────────────────
   • 不稳定因素:
     - 就诊行为随疫情严重程度变化
     - 其他呼吸道病原体共循环
     - 年龄结构变化
   • 建议使用"ILI+" (ILI × 病毒阳性率) 更稳定

3. 季节性H3N2特有考虑:
   ─────────────────────────────────────────────────────────────────────────
   • 南方夏季流行 vs 北方冬季流行
   • 抗原漂移速率快于H1N1
   • 疫苗效果通常低于H1N1
