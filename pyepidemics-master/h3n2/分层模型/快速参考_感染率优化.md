## 快速总结：优化后感染率仍高的原因与解决方案

### 📊 现象
| 场景 | 优化后感染率 | 改善幅度 | 峰值改善 |
|------|-----------|---------|--------|
| 常态 | **12.3%** | ✅✅ 改善84% | 峰值↓99% |
| 散发 | 93.6% | ❌ 仅改善3% | 峰值↓30% |
| 聚集 | 78.5% | ❌ 仅改善19% | 峰值↓70% |

**核心矛盾**：为什么峰值大幅下降但感染率改善有限？

---

### 🔍 根本原因（3个机制）

#### 1. **目标函数权重失衡**
```
感染率权重 (λ_AR = 1.0)    vs    峰值权重 (λ_P = 0.1)
    ↓ 相对太小                  ↓ 不够驱动
优化器偏好"压制峰值"而非"降低最终感染率"
```

#### 2. **指数惩罚函数在低感染率时失效**
```
A_integral = ∫ ω₁ × [exp(ω₂ × I/N) - 1] dt
           = ∫ 1.5 × [exp(12 × I/N) - 1] dt

当 I/N < 0.05（5%）时：
  exp(12 × 0.05) ≈ 1.8  → 惩罚项 ≈ 0.8 ✓ 有效
当 I/N < 0.01（1%）时：
  exp(12 × 0.01) ≈ 1.1  → 惩罚项 ≈ 0.1 ✗ 基本失效
```

#### 3. **防控成本与秩序扰动权重约束了激进干预**
```
目标函数平衡：
  J = A（疫情损失）+ C（防控成本）+ D（教学扰动）

成本权重（c_q=5.50）& 扰动权重（d_q_load=30.00）太大
→ 优化器在"可接受的低峰值处"停止投入
```

---

### ✅ 解决方案：参数调优

#### **最推荐：改进-平衡方案**
```python
改变项目              旧值    →  新值   |  改善效果
─────────────────────────────────────────────────
λ_AR(感染率权重)     1.00   →  5.00   | 5倍关注最终感染率
ω₂(指数系数)         12.00  →  10.00  | 防止指数饱和
c_q(隔离基础成本)    5.50   →  3.00   | 允许更激进防控
c_q2(隔离二次成本)   0.50   →  0.25   | 减弱成本曲线
d_q_load(负荷权重)   30.00  →  20.00  | 减轻扰动压力
```

**预期结果**：
- 感染率：93.6% → **80%～85%** (改善 8%～14%)
- 峰值：基本保持
- 防控成本：中等增加（可接受）

#### 如果想要最大改善：激进方案
```python
λ_AR: 1.00 → 8.00
ω₂: 12.00 → 8.00
c_q: 5.50 → 2.00
c_q2: 0.50 → 0.10
d_q_load: 30.00 → 15.00

预期：感染率 93.6% → 70%～80%，但防控成本较大
```

### 📈 为什么"常态"表现最好（12.3%）？

关键区别：
```
常态场景                          聚集场景
─────────────────────────────────────────────────
q_rate = 0.22                    q_rate = 0.12  (隔离能力差)
ω₂ = 8.00                        ω₂ = 12.00     (指数更强）
omega1 = 1.20                    omega1 = 1.50  (惩罚更强)

结果：隔离能力强 + 指数惩罚适中 + 早期切断
    → 感染曲线被"打断" → 最终感染率低
```

---

### 🧠 深层理解

**感染率 vs 峰值的本质区别**：
- **峰值** = "患者人数的瞬时最大值" → 反映医疗压力
- **感染率** = "累积被感染人口比例" → 反映疾病传播速度与隔离效率

**为什么降低峰值不等于降低感染率**？
```
例：即使压制感染速度使 I(t) 保持在低水平，
    缓慢而持续的感染仍会在200天后"积累"到70-90%

关键：要降低最终感染率，必须
      1. 提高隔离率（q_scale）→ 防控成本↑
      2. 强化非药物干预（口罩、线上等）→ 扰动↑
      3. 坚持长期（不能早期放松）
```
