# 为什么优化后的感染率仍然很高——机制剖析

## 提供的数据

| 场景 | 优化后感染率 | 优化后峰值 I | 无干预感染率 | 无干预峰值 I |
|------|----------|----------|-----------|------------|
| 常态 | 12.3% | 72 | ~96.5% | ~7600 |
| 散发 | 93.6% | 5780 | ~96.9% | ~8270 |
| 聚集 | 78.5% | 2880 | ~97.6% | ~9550 |

**关键观察**：虽然峰值大幅下降（下降85-90%），但最终感染率改善有限。  
- 常态：96.5% → 12.3%（改善84.2%），**表现最好**
- 散发、聚集：改善仅 ~3%（96.9%→93.6%，97.6%→78.5%）

---

## 根本原因分析

### 1️⃣ **"峰值"和"感染率"的优化目标本质不同**

#### A部分的三个分量：
```python
A = a_integral + a_ar + a_p

其中：
- a_integral  = ∫ω₁[exp(ω₂(E+I)/N) - 1] dt  # 时间积分，重视病例曲线面积
- a_ar        = λ_AR × R_final / N            # 最终累计感染率（全局损失）
- a_p         = λ_P  × I_peak / N             # 峰值感染人数（局部限制）
```

**权重对比（聚集场景）**：
- λ_AR = 1.00（感染率权重）
- λ_P  = 0.10（峰值权重）
- ω₁  = 1.50, ω₂ = 12.00（指数惩罚系数）

**问题**：
- 峰值项权重只有 0.10，感染率权重是 1.0，**峰值权重太小**
- 指数函数 exp(12×I/N) 在 I/N 小时快速饱和，只有在早期高感染率时才能有效"驱使"优化器
- 一旦病例被"压制"到中低水平，exp(12×低感染率) ≈ 1，**指数惩罚失效**

---

### 2️⃣ **"最终感染率"是约束而非直接目标**

关键数学事实：
$$\frac{dR}{dt} = \gamma I(t)$$

即使 **I(t) 被大幅压制**，只要模拟足够长（通常200天），绝大多数易感者最终仍会被感染或转移到其他状态。

#### 聚集场景的病理学根源：
```
基础隔离率 q_rate = 0.12（最低值）
隔离增益上限 q_gain_max = 3.0

→ 最大隔离速率 = 0.12 × (1 + 3.0) = 0.48/day

但同时：
- 基础传播系数 β₀ = 0.256
- 季节放大 β_max ≈ 0.256 × (1 + 0.225) ≈ 0.32
- 防控抵抗 (1 - u_effects) 最多削减 30-50%

→ 即使全力防控，R_eff ≈ 0.32/(0.48+0.77) ≈ 0.3～0.4 > 0.1

虽然峰值压制，但感染仍在继续进行，最终会"积累"到70-80%左右
```

---

### 3️⃣ **防控成本和教学秩序扰动压制了过度干预**

#### 目标函数权衡：
```python
J = A + C + D

其中 C、D 是"反向激励"
```

**C（防控成本）权重**（聚集）：
- c_o = 1.50（线上授课成本）
- c_q = 5.50（基础隔离强化成本）
- c_q2 = 0.50（隔离凸性成本，导致二阶递增）

**D（教学秩序扰动）权重**：
- d_o = 1.50（线上扰动）
- d_q_policy = 2.00（隔离政策本身的秩序扰动）
- d_q_load = 30.00（隔离人员心理负荷，积分项）

#### 优化器的"理性"决策：
```
若 λ_AR × ΔR_final = 0.1 ÷ N

而 C + D(q_scale) 的增长率 > 2~3/天

→ 优化器会停止进一步加强防控

即：降低最后1%的感染率 < 增加的成本和秩序扰动
```

---

### 4️⃣ **场景差异解释**

#### 为什么"常态"表现最好（12.3% vs 96.5%）？

**常态场景配置**：
```python
q_rate = 0.22  # 隔离能力强（vs 0.12 聚集）
gamma = 0.77   # 恢复快
ω₁ = 1.20      # 指数系数较低（vs 1.50）
ω₂ = 8.00      # 惩罚强度中等（vs 12.00）
```

**机制**：
- 隔离能力强 → 早期检出率高 → 可快速切断传播链
- 较弱的指数惩罚 → 允许更激进的防控
- **结果**：感染曲线被早期"打断"，最终感染率显著低于无干预

#### 为什么"散发"和"聚集"改善有限（~3%）？

**散发/聚集场景配置**：
```python
q_rate = 0.18 / 0.12  # 隔离能力受限
ω₂ = 12.00            # 指数惩罚超强
```

**机制**：
- 基础隔离能力差 → 早期检出和隔离都不足
- 强指数惩罚（ω₂=12）在低感染率时快速失效
- 防控成本/扰动权重相对感染率权重 → 优化器不愿进一步投入
- **结果**：峰值被压制（因病例数量下降），但**累积感染仍在缓慢进行**

---

## 为什么"峰值"和"感染率"如此不同步？

关键：**感染率反映的是累积概率，峰值反映的是瞬时容量**

$$\text{最终感染率} = \frac{\text{未接种且未感染人数经历过感染}}{总人口}$$

这个量取决于：
1. **接触速率**：即使压制峰值，缓慢接触仍在继续
2. **隔离效率**：隔离人员在"Q库"中，不能立即消除感染风险
3. **疫苗覆盖**：常态 20-12% vs 其他场景相近，保护作用有限
4. **模拟时间**：200天足够让大多数易感者"有机会"被感染

---

## 建议的改进方向

### 1. **提高感染率权重**
```python
# 聚集场景（当前）
lambda_AR = 1.00

# 建议改为
lambda_AR = 5.00～10.00  # 增大5～10倍
```
→ 使优化器在最终感染率上投入更多"努力"

### 2. **降低防控成本权重中的隔离成本**
```python
# 当前
c_q = 5.50
c_q2 = 0.50

# 建议
c_q = 2.00～3.00   # 降低线性成本
c_q2 = 0.10        # 大幅降低二次成本
```
→ 允许优化器更激进地强化隔离

### 3. **调整指数惩罚函数**
```python
# 当前（指数在低感染率时失效）
ω₁ × [exp(ω₂ × I/N) - 1]

# 建议：改为"线性 + 指数混合"
ω₁ × I/N + ω_exp × [exp(ω₂ × I/N) - 1]
```
→ 确保低感染率时仍有持续惩罚

### 4. **分场景调参**
- **散发/聚集**：ω₂ 应从 12.00 → 6.00～8.00（减弱指数饱和）
- **教学秩序扰动权重**：d_q_load 从 30.00 → 10.00～15.00（减轻隔离心理负荷权重）

---

## 核心结论

**高峰值下降 ≠ 高感染率下降**

- ✅ 优化成功压制了疫情峰值（实现医疗资源保护）
- ❌ 但未能显著降低最终感染率（因为优化目标中峰值权重太小）

**根本原因**：
1. 目标函数设计 → 峰值权重 (λ_P=0.10) << 感染率权重 (λ_AR=1.0)
2. 指数惩罚饱和 → 低感染率时失效
3. 成本-效益平衡 → 优化器在"可接受的低峰值"处停止投入

**修复方案**：重新调整 λ_AR、c_q、c_q2 以及 ω₁/ω₂，使优化目标更强烈地"追求"最终感染率的下降。
