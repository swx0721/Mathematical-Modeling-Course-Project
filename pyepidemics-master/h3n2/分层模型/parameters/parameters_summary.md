# 校园SVEIQR分层模型 - 先验参数汇总

## 概述

本文档完整列举三份校园SVEIQR分层模型代码文件中使用的所有需要人为设定的先验参数。模型涵盖三个场景：**常态**（baseline）、**散发**（sporadic）、**聚集**（cluster）。

---

## 一、基础流行病学参数

这些参数定义了病原体的内在特性，**所有三个场景共用相同值**。

| 参数名 | 默认值 | 单位 | 说明 |
|------|-------|------|------|
| `beta0` | 0.858 | 1/天 | 基础传播率（未经干预、无季节调整） |
| `sigma` | 1.161 | 1/天 | 潜伏期逆数（1/潜伏期）；潜伏期 ≈ 0.86天 |
| `gamma` | 0.770 | 1/天 | 恢复率（不计隔离）；感染期 ≈ 1.3天 |
| `q_release` | 0.15 | 1/天 | 隔离解除率；平均隔离持续时间 ≈ 6.7天 |

**科学来源**：
- `beta0, sigma, gamma` 源自上海新冠H3N2疫情数据拟合（基准论文）
- `q_release` 参考实地隔离管理政策，约为7天隔离期

---

## 二、疫苗参数

定义疫苗的保护效率和人群覆盖率（基准值）。**所有三个场景共用相同值**。

| 参数名 | 默认值 | 单位 | 说明 |
|------|-------|------|------|
| `ve_s` | 0.38 | 无量纲 | 学生的疫苗保护效率（VE）；值域 [0, 1] |
| `ve_t` | 0.305 | 无量纲 | 教师的疫苗保护效率（VE） |
| `ve_l` | 0.375 | 无量纲 | 后勤/管理的疫苗保护效率（VE） |
| `v_cov_s` | 0.30 | 无量纲 | 学生疫苗覆盖率（基准）；值域 [0, 1] |
| `v_cov_t` | 0.40 | 无量纲 | 教师疫苗覆盖率（基准） |
| `v_cov_l` | 0.40 | 无量纲 | 后勤疫苗覆盖率（基准） |
| `vax_cov_scale` | 1.0 | 无量纲 | 疫苗覆盖率缩放因子；**优化变量**，值域 [0, 5] |

**说明**：
- 实际覆盖率 = 基准覆盖率 × `vax_cov_scale`，经过剪裁保证 ∈ [0, 1]
- 例：学生实际覆盖率 = min(0.30 × `vax_cov_scale`, 1.0)
- VE值基于疫苗类型和变异株特性的文献综合

## 三、季节性参数

模拟呼吸道病原体的自然季节波动。**所有三个场景共用相同值**。

| 参数名 | 默认值 | 单位 | 说明 |
|------|-------|------|------|
| `season_amp` | 0.225 | 无量纲 | 季节幅度系数；传播率在冬季峰值约为基值的 (1 + 0.225) = 1.225倍 |
| `season_phase` | 30.0 | 天 | 季节峰值相位（冬季开始日期）；从模拟开始日计数 |

**数学形式**：
$$\beta(t) = \beta_0 \times \left[1 + \text{season\_amp} \times \cos\left(\frac{2\pi(t - \text{season\_phase})}{365}\right)\right]$$

## 四、隔离系统参数

定义隔离政策的有效性和容量约束。**基础值**因场景而异，但所有隔离相关参数具有如下功能。

### 4.1 基础隔离率（场景特定）

| 参数名 | 常态 | 散发 | 聚集 | 单位 | 说明 |
|------|-----|-----|-----|------|------|
| `q_rate` | 0.22 | 0.18 | 0.12 | 1/天 | 基础隔离率；被检出后进入隔离的速率 |

**设定逻辑**：
- 常态（低风险）：隔离能力较强 → q_rate = 0.22
- 散发（中风险）：隔离能力中等 → q_rate = 0.18
- 聚集（高风险）：隔离能力受限 → q_rate = 0.12

### 4.2 隔离饱和参数（**所有场景相同**）

| 参数名 | 默认值 | 单位 | 说明 |
|------|-------|------|------|
| `q_sat_k` | 1.0 | 无量纲 | Michaelis-Menten饱和系数；控制隔离对e_scale的响应曲线 |
| `q_gain_max` | 3.0 | 无量纲 | 最大隔离增益倍数；当 q_scale → ∞ 时，隔离率最多增至基值的 (1 + 3.0) = 4倍 |
| `q_capacity_alpha` | 10.0 | 无量纲 | 容量应激系数；高感染率时隔离能力下降的陡峭度 |
| `q_rate_cap` | 1.0 | 无量纲 | 隔离率的硬上界（单位化后）；防止不物理的极高隔离率 |
| `q_scale` | 1.0 | 无量纲 | 隔离强度缩放因子；**优化变量**，值域 [0, 10] |

**隔离速率计算公式**（在ODE中实现）：
$$q_{\text{response}} = \frac{q_{\text{scale}}}{q_{\text{sat\_k}} + q_{\text{scale}}}$$
$$q_{\text{rate\_cmd}} = q_{\text{rate}} \times (1 + q_{\text{gain\_max}} \times q_{\text{response}})$$
$$q_{\text{rate\_eff}} = \frac{q_{\text{rate\_cmd}}}{1 + q_{\text{capacity\_alpha}} \times \frac{I_{\text{total}}}{N}} $$
$$q_{\text{rate\_eff}} = \text{clip}(q_{\text{rate\_eff}}, 0, q_{\text{rate\_cap}})$$

**物理意义**：
- **饱和项** $q_{\text{response}}$ ∈ [0, 1)：随q_scale增加而饱和，模建边际效应递减
- **容量项** $(1 + q_{\text{capacity\_alpha}} \times I/N)$：高感染率时隔离能力被挤压（类似医疗资源有限）
- **硬限** $q_{\text{rate\_cap}}$：确保隔离率不超过生物学或操作上的上界

## 五、干预措施参数

定义各种防控措施对病原体传播的阻滞效果。**所有三个场景共用相同值**。

| 参数名 | 默认值 | 单位 | 说明 | 应用于 |
|------|-------|------|------|--------|
| `mask_effect` | 0.18 | 无量纲 | 口罩的相对降低颗粒物传播效率 | 宿舍、食堂、社团 |
| `vent_effect` | 0.30 | 无量纲 | 通风系统对教室传播的相对抑制 | 教室 |
| `online_effect` | 0.715 | 无量纲 | 在线教学对教室接触的相对削减 | 教室 |
| `club_limit_effect` | 0.40 | 无量纲 | 社团活动限制对社团场所接触的相对削减 | 社团 |
| `disinfect_effect` | 0.175 | 无量纲 | 消毒措施对环境传播的相对降低 | 教室、食堂 |
| `mask_u` | 0.0 | 无量纲 | 口罩使用强度；**优化变量**，值域 [0, 1] | - |
| `vent_u` | 0.0 | 无量纲 | 通风水平；**优化变量**，值域 [0, 1] | - |
| `online_u` | 0.0 | 无量纲 | 在线教学比例；**优化变量**，值域 [0, 1] | - |
| `club_u` | 0.0 | 无量纲 | 社团限制强度；**优化变量**，值域 [0, 1] | - |
| `disinfect_u` | 0.0 | 无量纲 | 消毒措施强度；**优化变量**，值域 [0, 1] | - |

**传播率调整规则**（在 `adjusted_place_beta` 中实现）：
- **教室**：$\beta_{\text{adj}} = \beta \times (1 - v_{\text{eff}} \times v_u) \times (1 - d_{\text{eff}} \times d_u) \times (1 - o_{\text{eff}} \times o_u)$
- **宿舍/食堂**：$\beta_{\text{adj}} = \beta \times (1 - m_{\text{eff}} \times m_u) \times (1 - d_{\text{eff}} \times d_u)$
- **社团**：$\beta_{\text{adj}} = \beta \times (1 - m_{\text{eff}} \times m_u) \times (1 - c_{\text{eff}} \times c_u)$

## 六、接触矩阵及场所权重

定义不同人群在不同场所的接触强度。

### 6.1 场所权重（**所有场景相同**）

| 场所 | 权重 | 说明 |
|-----|------|------|
| `dorm`（宿舍） | 0.35 | 最高权重；学生宿舍为主要接触场所 |
| `class`（教室） | 0.40 | 次高权重；课堂集中教学 |
| `canteen`（食堂） | 0.15 | 中等权重；三餐时段集中用餐 |
| `club`（社团） | 0.10 | 最低权重；课外兴趣活动 |

**归一化**：权重自动归一化为 Σ = 1.0

### 6.2 接触矩阵

三群体（学生 s、教师 t、后勤 l）在四个场所的接触强度矩阵，从场景特定的基础值乘以缩放因子得到。

**接触矩阵缩放因子**（场景通用）：
- 宿舍：1.10
- 教室：1.08
- 食堂：1.10
- 社团：1.20

**宿舍接触矩阵示例**（基础值→缩放后）：

| 群体 | 学生 | 教师 | 后勤 |
|-----|------|------|------|
| 学生 | 8.5×1.10 = 9.35 | 0.3×1.10 = 0.33 | 0.2×1.10 = 0.22 |
| 教师 | 0.2×1.10 = 0.22 | 0.1×1.10 = 0.11 | 0.05×1.10 = 0.055 |
| 后勤 | 0.3×1.10 = 0.33 | 0.05×1.10 = 0.055 | 0.4×1.10 = 0.44 |

**教室、食堂、社团矩阵类似**，使用各自的缩放因子。

## 十、目标函数权重

### 10.1 疫情损失权重

定义病情严重程度的指数衰减权重。**因场景而异**。

| 权重参数 | 常态 | 散发 | 聚集 | 说明 |
|---------|-----|-----|-----|------|
| `omega1` | 1.00 | 1.20 | 1.50 | 指数函数的线性系数；值越大，边际成本越高 |
| `omega2` | 6.00 | 8.00 | 12.00 | 指数函数的指数系数；值越大，高感染率时惩罚越严厉 |

**疫情损失计算**（目标函数的A部分）：
$$A = \int_0^T \omega_1 \left[\exp(\omega_2 (e + i + q)/N) - 1\right] dt$$

其中 $e, i, q$ 为E、I、Q仓室总数，N为总人口。

**场景逻辑**：
- 常态：较低权重，允许轻度感染
- 聚集：极高权重（ω1=1.5, ω2=12），强力控制需求

### 10.2 防控成本权重

定义各干预措施的单位成本。**所有场景相同**。

| 成本参数 | 值 | 单位 | 说明 |
|--------|-----|------|------|
| `c_m` | 1.00 | 无量纲 | 口罩单位成本权重 |
| `c_v` | 1.50 | 无量纲 | 通风单位成本权重 |
| `c_o` | 8.00 | 无量纲 | 在线教学单位成本权重（最高，教学扰动大） |
| `c_c` | 3.00 | 无量纲 | 社团限制单位成本权重 |
| `c_d` | 2.00 | 无量纲 | 消毒单位成本权重 |
| `c_vax` | 10.00 | 无量纲 | 增加疫苗覆盖率的单位成本权重 |
| `c_q` | 2.00 | 无量纲 | 基础隔离强化成本（一次项） |
| `c_q2` | 0.50 | 无量纲 | 隔离超额成本（二次项，模建凸性） |

**防控成本计算**（目标函数的C部分）：
$$C = T \times \sum_{u \in \text{controls}} c_u \times u + T \times (c_q \times q_{\text{excess}} + c_{q2} \times q_{\text{excess}}^2)$$

其中 $q_{\text{excess}} = \max(0, q_{\text{scale}} - 1)$，T是模拟时间跨度。

### 10.3 教学秩序扰动权重

定义社会/教学损失的外部性。**因场景略异**。

| 扰动参数 | 常态 | 散发 | 聚集 | 单位 | 说明 |
|--------|-----|-----|-----|------|------|
| `d_o` | 5.00 | 5.00 | 4.00 | 无量纲 | 在线教学对教学秩序的单位扰动 |
| `d_c` | 2.00 | 2.00 | 1.50 | 无量纲 | 社团限制对课外活动的单位扰动 |
| `d_q_policy` | 1.00 | 1.00 | 1.00 | 无量纲 | 隔离政策本身对秩序的单位扰动 |
| `d_q_load` | 30.00 | 30.00 | 30.00 | 无量纲 | 隔离人员持续负荷的单位扰动系数 |

**教学秩序扰动计算**（目标函数的D部分）：
$$D = T \times (d_o \times o_u + d_c \times c_u + d_{q_{\text{policy}}} \times q_{\text{scale}}) + d_{q_{\text{load}}} \times \int_0^T \frac{Q(t)}{N} dt$$

**组分说明**：
- 前三项：政策措施导致的直接损失
- 最后项：隔离人员持续积累的社会心理负荷

## 十一、优化问题定义

### 11.1 决策变量和界限

| 变量名 | 下界 | 上界 | 单位 | 说明 |
|------|------|------|------|------|
| `mask_u` | 0.0 | 1.0 | 无量纲 | 口罩覆盖强度 |
| `vent_u` | 0.0 | 1.0 | 无量纲 | 通风水平 |
| `online_u` | 0.0 | 1.0 | 无量纲 | 在线教学比例 |
| `club_u` | 0.0 | 1.0 | 无量纲 | 社团活动限制 |
| `disinfect_u` | 0.0 | 1.0 | 无量纲 | 消毒强度 |
| `vax_cov_scale` | 0.0 | 5.0 | 无量纲 | 疫苗覆盖率缩放因子 |
| `q_scale` | 0.0 | 10.0 | 无量纲 | 隔离强化因子 |

### 11.2 优化算法

- **全局优化阶段**：差分进化算法（`differential_evolution`）
  - 最大代数：50
  - 种群大小：自适应
  
- **局部优化阶段**：L-BFGS-B方法（`minimize` with 'L-BFGS-B'）
  - 最大迭代数：40
  - 梯度公差：自适应

### 11.3 目标函数

$$J = A + C + D$$

其中A、C、D如前所述。
