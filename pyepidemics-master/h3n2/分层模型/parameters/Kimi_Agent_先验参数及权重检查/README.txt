
上海高校H3N2疫情传播动力学模型 - 先验参数检查项目
{'='*80}

项目概述
{'-'*80}
本项目对上海高校H3N2疫情传播动力学模型中使用的34个先验参数进行了全面检查,
基于权威文献和上海本地监测数据,评估各参数的合理性,并提出修正建议。

检查方法
{'-'*80}
1. 文献调研: 检索中国CDC、WHO、PubMed等权威数据库
2. 数据收集: 收集上海流感监测数据(2015-2024)
3. 参数对比: 将模型参数与文献报道值进行对比
4. 合理性评估: 评估每个参数的合理性(合理/偏高/偏低)
5. 修正建议: 对不合理的参数提出具体修正值

主要发现
{'-'*80}
• 检查参数总数: 34个
• 合理参数: 27个 (79.4%)
• 偏高参数: 5个 (14.7%)
• 偏低参数: 2个 (5.9%)

需要调整的参数(7个):
1. beta0 (基础传播率): 0.858 → 0.60
2. gamma (恢复率): 0.770 → 0.17
3. v_cov_s (学生疫苗覆盖率): 0.30 → 0.20
4. v_cov_t (教师疫苗覆盖率): 0.40 → 0.12
5. v_cov_l (后勤疫苗覆盖率): 0.40 → 0.12
6. mask_effect (口罩效果): 0.18 → 0.40
7. disinfect_effect (消毒效果): 0.175 → 0.60
