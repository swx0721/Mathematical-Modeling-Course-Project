
上海高校H3N2疫情传播动力学模型 - 先验参数检查报告
================================================================================

一、检查概况
--------------------------------------------------------------------------------
• 检查参数总数: 34 个
• 合理参数: 27 个 (79.4%)
• 偏高参数: 5 个 (14.7%)
• 偏低参数: 2 个 (5.9%)

二、数据来源
--------------------------------------------------------------------------------
本次参数检查基于以下权威数据源:
1. 中国疾病预防控制中心(CDC)流感监测数据
2. 世界卫生组织(WHO)流感指南
3. 上海市流感监测周报(2015-2024)
4. 国际学术文献(PubMed, Google Scholar)
5. 上海高校流感疫苗接种调查数据

三、关键发现
--------------------------------------------------------------------------------

(一) 需要调整的参数(共7个)

1. 基础流行病学参数(2个)
   • beta0(基础传播率): 0.858 → 0.6
     - 问题: 对应R0≈2.1-3.1,高于季节性流感典型值(1.19-1.37)
     - 依据: 文献报道季节性流感R0中位数1.28(IQR: 1.19-1.37)

   • gamma(恢复率): 0.770 → 0.17
     - 问题: 对应传染期1.3天,远低于文献报道的5-7天
     - 依据: CDC报道成人传染期5-7天,儿童可达10天

2. 疫苗参数(3个)
   • v_cov_s(学生疫苗覆盖率): 0.30 → 0.20
     - 问题: 30%高于上海实际监测数据
     - 依据: 上海闵行2023/24季学生接种率20.84%

   • v_cov_t(教师疫苗覆盖率): 0.40 → 0.12
     - 问题: 40%远高于中国成人接种率
     - 依据: 中国成人总体接种率仅2.5-3.2%

   • v_cov_l(后勤疫苗覆盖率): 0.40 → 0.12
     - 问题: 同教师群体
     - 依据: 同教师群体

3. 干预措施参数(2个)
   • mask_effect(口罩效果): 0.18 → 0.40
     - 问题: 18%低于文献报道的30-53%
     - 依据: 系统综述显示口罩可降低53%发病率

   • disinfect_effect(消毒效果): 0.175 → 0.60
     - 问题: 17.5%远低于文献报道的50-77%
     - 依据: 每天消毒可降低77%传播风险

(二) 合理的参数(共27个)

主要合理的参数包括:
• 潜伏期逆数(sigma): 对应潜伏期0.86天,在合理范围
• 季节性幅度(season_amp): 22.5%,符合上海季节性特征
• 隔离解除率(q_release): 对应隔离期6.7天,符合WHO建议
• 场所权重: 宿舍35%、教室40%、食堂15%、社团10%,分布合理
• 人群构成: 学生26,000、教师1,700、后勤800,符合高校典型规模

四、重要支撑数据
--------------------------------------------------------------------------------

1. 季节性流感R0估计
   • 中位数: 1.28 (IQR: 1.19-1.37)
   • H3N2亚型: 1.25 (IQR: 1.18-1.27)
   • 来源: Biggerstaff et al., 2014; 多项系统综述

2. 疫苗保护效率(VE)
   • H3N2总体: 33-41%
   • 儿童(≤17岁): 35.8-68.7%
   • 成人(18-59岁): 25.3-41.3%
   • 老年人(≥60岁): 25.3%
   • 来源: 中国CDC, 北京2025/26季研究, 苏州2025/26季研究

3. 中国疫苗接种率
   • 总体人群: 2.5-3.2%
   • 上海老年人: 8.2%
   • 上海学生(2023/24): 20.84%
   • 来源: 上海浦东研究, 闵行研究

4. 防控措施效果
   • 口罩: 降低53%发病率
   • 通风: 降低40-60%传播风险
   • 消毒: 降低77%传播风险
   • 手部卫生: 降低约50%传播风险
   • 来源: WHO, CDC, 多项系统综述

5. 上海流感监测特征
   • 季节性: 冬季和夏季双峰
   • 主要毒株: H3N2(49.78%), H1N1(30.03%)
   • 阳性率: 17.60%
   • 来源: 上海市虹口区、嘉定区CDC监测数据(2015-2024)

五、修正建议
--------------------------------------------------------------------------------

基于以上分析,建议对以下7个参数进行修正:

参数名              当前值    推荐修正值    调整幅度
------------------------------------------------------------
beta0              0.858     0.60        -30.1%
gamma              0.770     0.17        -77.9%
v_cov_s            0.30      0.20        -33.3%
v_cov_t            0.40      0.12        -70.0%
v_cov_l            0.40      0.12        -70.0%
mask_effect        0.18      0.40       +122.2%
disinfect_effect   0.175     0.60       +242.9%

六、模型影响评估
--------------------------------------------------------------------------------

参数修正对模型的预期影响:

1. 降低传播强度(beta0降低30%)
   • 预期效果: 降低疫情峰值和累计感染人数
   • 合理性: 更符合季节性流感的实际传播强度

2. 延长传染期(gamma降低78%)
   • 预期效果: 延长个体感染持续时间,增加传播机会
   • 合理性: 更符合实际传染期5-7天的文献报道

3. 降低疫苗覆盖率(降低33-70%)
   • 预期效果: 降低群体免疫水平,增加易感人群
   • 合理性: 更符合中国实际接种率水平

4. 提高防控措施效果(提高122-243%)
   • 预期效果: 增强防控措施的保护作用
   • 合理性: 更符合文献报道的防控效果

七、结论
--------------------------------------------------------------------------------

本次参数检查基于权威文献和上海本地监测数据,对模型中的34个先验参数
进行了全面评估。结果显示:

• 79.4%(27/34)的参数设置合理
• 20.6%(7/34)的参数需要调整

主要问题集中在:
1. 传播率(beta0)偏高,可能导致疫情被高估
2. 恢复率(gamma)偏高,导致传染期被低估
3. 疫苗覆盖率偏高,不符合中国实际情况
4. 防控措施效果偏低,低估了非药物干预的作用

建议按照本报告的推荐值进行参数修正,以提高模型的准确性和可靠性。
修正后的模型将更符合上海高校H3N2疫情的实际传播特征。
